# LLM-шлюз и переключение провайдеров (Provider Failover) для Claude Code — Swobu

**Сохраняйте один стабильный эндпоинт Claude Code. Перенесите маршрутизацию и отказоустойчивость на уровень шлюза.**

Swobu подключает Claude Code к единому стабильному локальному эндпоинту. Изменяйте доступные мощности провайдеров и настраивайте аварийное переключение (Provider Failover) за этим эндпоинтом без необходимости постоянно переписывать конфигурацию Claude Code или переменные окружения.

## Зачем нужен Swobu?

При интенсивной разработке с Claude Code команды часто сталкиваются с лимитами запросов (Rate Limits), сбоями в облачной инфраструктуре или задачей мультиоблачного резервирования (Anthropic, AWS Bedrock, Google Cloud Vertex AI, Microsoft Foundry). Традиционный подход требует вручную менять `ANTHROPIC_BASE_URL` или переключать профили с перезапуском процессов.

Swobu меняет этот процесс: подключите Claude Code к Swobu один раз, и локальный шлюз возьмет на себя выбор маршрута, согласование протоколов и автоматическое переключение на резервные целевые сервисы.

## Установка и настройка (Install)

Выполните следующие команды в Claude Code для добавления и установки плагина:

```text
/plugin marketplace add swobuforge/swobu-claude-plugin
/plugin install swobu@swobu
```

После установки выполните инициализацию и подключение:

```text
/swobu:setup
/swobu:connect
```

Если у вас настроено несколько рабочих пространств (workspaces), укажите нужное явно:

```text
/swobu:connect work
```

## Что меняет Swobu

- **Единый стабильный эндпоинт**: Claude Code всегда обращается к фиксированному локальному адресу, исключая постоянные правки клиентского конфига.
- **Автоматический отказоустойчивый переход**: При превышении квот или ошибках основного провайдера Swobu прозрачно перенаправляет запросы на резервные цели (такие как AWS Bedrock или Vertex AI).
- **Легковесная архитектура**: Плагин является тонким связующим звеном между Claude Code и локальным CLI `swobu`, не создавая лишней нагрузки на систему.

## Границы безопасности и инварианты доверия (Trust Invariants)

- **Без хранения API-ключей**: Плагин не сохраняет API-ключи провайдеров; все учетные данные изолированы в локальном хранилище Swobu.
- **Зона ответственности маршрутизации**: Плагин не выполняет маршрутизацию самостоятельно; все задачи маршрутизации, совместимости и отказоустойчивости выполняет Swobu.
- **Соблюдение правил биллинга и доступа**: Плагин не предназначен для обхода официального биллинга, аккаунтных лимитов или региональных ограничений Anthropic.
- **Границы поддержки моделей**: Anthropic указывает, что сторонние шлюзы не делают модели сторонних семейств официально поддерживаемыми внутри Claude Code; Swobu маршрутизирует запросы только при условии, что целевой провайдер может представить требуемую семантику.

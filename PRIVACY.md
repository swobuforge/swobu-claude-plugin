# Privacy

The Swobu Claude Code plugin collects and transmits no prompts, conversation
content, credentials, configuration files, analytics, or plugin-specific user
data.

The plugin may ask Claude Code to run the locally installed `swobu` command.
Claude Code's normal Bash permission flow applies. `/swobu:setup` only prints
the official installation command; it never downloads or executes it.

Provider and Claude credentials remain owned by Swobu and Claude respectively.
Security reports should be sent to `security@swobu.com`.

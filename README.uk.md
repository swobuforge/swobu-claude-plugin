# LLM-шлюз та відмовостійке перемикання провайдерів (Provider Failover) для Claude Code — Swobu

**Зберігайте єдину стабільну кінцеву точку Claude Code. Перенесіть маршрутизацію та відмовостійкість на рівень шлюзу.**

Swobu підключає Claude Code до єдиної стабільної локальної кінцевої точки (endpoint). Змінюйте доступні потужності провайдерів та налаштовуйте резервне перемикання (Provider Failover) за цією точкою без необхідності щоразу змінювати конфігурацію Claude Code або змінні середовища.

## Чому саме Swobu?

Під час інтенсивної роботи з Claude Code розробники часто стикаються з лімітами запитів (Rate Limits), тимчасовими збоями або необхідністю мультихмарного резервування (Anthropic, AWS Bedrock, Google Cloud Vertex AI, Microsoft Foundry). Традиційний підхід вимагає редагування `ANTHROPIC_BASE_URL` або перезапуску процесів для зміни профілів.

Swobu пропонує краще рішення: підключіть Claude Code до Swobu один раз, і локальний шлюз автоматично керуватиме вибором маршруту, сумісністю протоколів та перемиканням на резервні провайдери.

## Встановлення та налаштування (Install)

Виконайте наступні команди у Claude Code для додавання та встановлення плагіна:

```text
/plugin marketplace add swobuforge/swobu-claude-plugin
/plugin install swobu@swobu
```

Після встановлення запустіть налаштування та підключення:

```text
/swobu:setup
/swobu:connect
```

Якщо у вас налаштовано кілька робочих просторів (workspaces), вкажіть потрібний явно:

```text
/swobu:connect work
```

## Що змінює Swobu

- **Єдина фіксована кінцева точка**: Claude Code завжди звертається до постійної локальної адреси без повторних правок клієнтського конфігуратора.
- **Автоматичне та впорядковане перемикання**: У разі помилок або вичерпання лімітів головного провайдера Swobu прозоро перенаправляє запити на резервні цілі (наприклад, AWS Bedrock або Vertex AI).
- **Легка архітектура**: Плагін є простим містком між Claude Code та локальним CLI `swobu`, не створюючи зайвого навантаження на систему.

## Межі безпеки та інваріанти довіри (Trust Invariants)

- **Без збереження API-ключів**: Плагін не зберігає жодних ключів API провайдерів; усі облікові дані залишаються в локальному сховищі Swobu.
- **Власність маршрутизації**: Плагін не виконує власної маршрутизації; Swobu повністю відповідає за маршрутизацію, сумісність та резервування.
- **Дотримання умов білінгу та доступу**: Плагін не обходить офіційний білінг, ліміти облікових записів або географічні обмеження Anthropic.
- **Межі підтримки моделей**: Anthropic зазначає, що сторонні шлюзи не роблять моделі сторонніх архітектур офіційно підтримуваними всередині Claude Code; Swobu маршрутизує запити лише тоді, коли цільовий провайдер може коректно представити необхідну семантику.
